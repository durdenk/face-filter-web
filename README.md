# Face Age and Wrinkle Scanner web assets

Static landing and legal pages for the Face Age and Wrinkle Scanner Android app.

- `index.html`: product landing page
- `privacy-policy.html`: privacy and data-deletion information
- `terms-of-use.html`: terms of use
- `styles.css`: shared responsive design
- `faceage_logo.png`: Face Age and Wrinkle Scanner app artwork
- `app-ads.txt`: advertising verification
